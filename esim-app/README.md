JD7Co eSIM Platform

Overview

Этот репозиторий содержит scaffold для JD7Co eSIM приложения (Android + Backend + Infrastructure).

Partner programs

В целях безопасности и удобства в репозитории используются placeholder-реферальные ссылки. Примеры (замените на реальные):

- Airalo: https://airalo.com/?ref=JD7CO_AIRALO
- Nomad: https://getnomad.app/?ref=JD7CO_NOMAD
- Truphone: https://truphone.com/?ref=JD7CO_TRUPHONE
- GigSky: https://gigsky.com/?ref=JD7CO_GIGSKY
- Ubigi: https://ubigi.com/?ref=JD7CO_UBIGI
- RedteaGO: https://redteago.com/?ref=JD7CO_REDTEAGO
- KeepGo: https://keepgo.com/?ref=JD7CO_KEEPGO
- Flexiroam: https://flexiroam.com/?ref=JD7CO_FLEXIROAM
- Transatel: https://transatel.com/?ref=JD7CO_TRANSATEL
- DENT Wireless: https://dentwireless.com/?ref=JD7CO_DENT

Как заменить:
- Замените referral_url в backend partners_db на ваши реальные ссылки.
- Для приватности храните реальные ссылки в .env или в секретах и используйте redirect-эндпоинт на бэкенде.
